# S1 体验与验收

交付状态（2026-09-06）：**软件完成并已安装，真机基础移动已观察到；正式实体验收待完成。**

这份说明用于自己体验和之后集中验收。完整技术证据、源码位置、限制及回退方法见 [S1 交付记录](SPATIAL_S1.md)。S2 弹珠功能尚未开始，仍以 S1 正式验收通过为前提。

## 现在能体验什么

- 真实手机左右、上下、前后移动时，Web 中的手机模型改变位置，面板显示相对 XYZ，单位是米。
- 真实手机旋转和倾斜时，模型改变方向；校准保留重力方向以及真实俯仰、侧倾。
- 工作区提供 10 cm 网格、原点标记和短轨迹；鼠标可调整观察角度，`Reset view` 恢复观察视角。
- 追踪受限、数据过期或连接断开时，模型冻结并显示状态；恢复后点击 `Set origin` 才继续。
- 原有 `Screen mirroring` 模式仍保留，需要在两端选择该模式并按原来的系统共享流程启动。

空间模式里的手机屏幕显示静态 `TOP / Spatial / 6DoF · S1` 方向标识。S1 尚无弹珠、碰撞、倒出与接回交互。后摄图像仅在手机本地用于追踪，不传到电脑，也不保存。

## 第一次打开：按这个顺序

1. Mac 打开本轮入口 **http://127.0.0.1:14317/**，选择 `Spatial tracking`。
2. 用数据线连接 iPhone 与 Mac，保持手机解锁。首轮按已验证条件体验；线插上不保证已有网络连接自动改走 USB，若仍频繁断流，先停下排查连接路线。
3. iPhone 打开 **Phone 3D Studio → Spatial tracking → Start tracking**。首次使用允许摄像头，体验期间保持 App 在前台。
4. 手机悬空拿稳：**屏幕朝上，灵动岛那一端朝向 Mac，后摄朝下**。在后摄下面放一本打开的书或有图案的桌垫，距离约 20–40 cm，保持光线足够且镜头无遮挡。
5. 等网页显示 `Ready to set origin`，点击 **`Set origin`**。出现 `Tracking live` 后开始移动。

灵动岛朝 Mac 是在确定水平方向，后摄仍应朝桌面；无需把摄像头对准电脑。若校准时灵动岛朝自己，左右参考方向会与上述约定相反。

当前页面与桥接分别使用 14317、4319 端口。本轮不要打开带 `bridge=...14319` 的旧测试链接。此链接是本机入口；重启后若页面打不开，按 [交付记录的启动说明](SPATIAL_S1.md#run) 恢复当前实施副本的服务。

## 快速体验：先确认能否自然跟随

这部分可以没有尺子。每个动作只做一遍，停住看结果；徒手距离用于观察功能，不用于精度结论。

| 你的动作 | 预期看到的变化 |
| --- | --- |
| 保持朝向和高度，向左 / 右移动再返回 | 相对 X 减小 / 增大，模型随之移动 |
| 尽量保持水平位置，抬高 / 放低 | 相对 Y 增大 / 减小 |
| 保持高度，靠近 Mac / 靠近自己 | 相对 Z 减小 / 增大 |
| 原地转向或倾斜 | 模型对应旋转、倾斜；仅点击 Set origin 不会把真实倾斜压平 |
| 鼠标拖动观察视角，然后点 Reset view | 观察相机复位，手机的物理原点不改变 |

XYZ 按设置原点时确定的工作区方向解释。鼠标转动视角后，画面投影中的左右可能不同，可点 `Reset view` 再对照数值。重新点击 `Set origin` 会建立新的位置和水平参考；往返验证期间不要重设原点。

`0.200 m` 的初始模型高度是展示约定。网格不代表真实桌面，也没有测量手机与显示器的位置关系。

## 状态提示怎么处理

| 页面状态 | 含义与下一步 |
| --- | --- |
| Waiting for iPhone | 没有收到手机连接；回到手机 App，确认正在 Spatial tracking、连接可达。此时冻结的数字不是当前手机位置。 |
| Ready to set origin | 当前追踪可用；按规定姿势拿稳，点击 Set origin。 |
| Tracking live | 当前已校准，模型正在跟随。 |
| Tracking limited | 暂不可信；清理后摄视野、改善光线和纹理。恢复正常后重新设置原点。 |
| Tracking paused | 位姿过期或工作区曾隐藏；模型冻结。恢复新鲜数据后重新设置原点。 |
| Needs attention | 根据手机和网页提示处理摄像头权限、设备支持或会话错误。 |

遮挡镜头、切手机后台、连接中断后，出现明确冻结提示属于预期保护。恢复时应先停住，再校准；模型不应把重新定位的跳变演成一次真实移动。刷新或隐藏网页后也可能需要重新校准。

结束体验时在手机点 **Stop tracking**，即可停止空间追踪和摄像头使用。

## 正式验收：集中做一次并记录

准备尺子或可靠的实物刻度、可重复定位的起点/终点标记、角度参考，以及能同时拍到真实手机与 Mac 画面的另一台相机。手机保持悬空，标记应能帮助同一个机身参考点回到原位；不要用虚拟网格代替实物刻度。

开始前，在网页展开 **Tracking details → Record numeric telemetry**，再设置原点。用外部相机连续记录手机与电脑的同框画面。

| 验收项 | 操作 | 通过标准 |
| --- | --- | --- |
| 三个平移轴 | 分别向右、向上、向 Mac 移动实测 20 cm 并返回；每轴重复 3 次，同一组中不重设原点 | 每次终点相对目标的三维误差、返回相对原点的三维偏差均不超过 3 cm |
| 旋转 | 用角度参考做 0°、45°、90°及返回 | 方向和旋转轴一致，中间过程无翻转；校准保留真实倾斜。记录角度与现象，不另行宣称未约定的角度精度 |
| 连续使用 | 正常视野下连续使用 5 分钟 | 无无提示的冻结或位置跳变；若冻结，有明确状态解释 |
| 遮挡恢复 | 遮挡后摄使追踪失效，再移开 | 冻结且提示原因；恢复正常后要求 Set origin，校准前不自动继续移动 |
| 后台恢复 | 手机切后台再回来；另检查网页刷新 | 会话恢复后要求重新校准，不沿用失效原点 |
| 连接恢复 | 实际中断所用连接，再恢复 | 明确冻结/断开；重连后要求校准。拔线后若仍走 Wi-Fi，不能算断网试验 |
| 投屏回归 | 停止空间模式，在手机和 Web 选择 Screen mirroring，启动系统共享 | 原有屏幕画面与旋转同步可以启动，空间与投屏来源不会同时驱动模型 |

三个正向目标分别为 `[+0.200, 0, 0]`、`[0, +0.200, 0]`、`[0, 0, -0.200]` m；返回目标均为 `[0, 0, 0]`。三维误差按三个轴误差平方和开方计算，使用页面的相对 XYZ，不使用原始相机坐标。3 cm 是本项目的实验门槛。

完成后点 **Stop & download telemetry**，确认 JSON 文件确实保存，并与同框视频、实物距离和试验记录放在一起。若出现保存窗口，完成保存；若文件未落盘，该项保持“记录待补”。本轮 Chrome 导出已验证，内置浏览器的下载落盘仍未确认。不要把合成 fixture 文件当成真机数据。

记录上限为 100,000 条，覆盖约 5 分钟的 60 Hz 位姿与最高 240 Hz 渲染提交。较长验收分段保存；出现 `Recording full` 或 JSON 中 `droppedRecords` 非零的片段不能证明完整过程。`Sample age` 是软件采样时间差，不能证明人眼看到的端到端延迟。

## 当前已经确认到哪一步

- 软件检查：360 项 Web/协议测试、47 项 Swift 测试、类型检查、lint、生产构建及 iPhone 真机目标构建通过。最后的记录容量调整另通过 18 项空间测试、类型检查、lint 和生产构建。
- 新版已安装到原有 iPhone App。授权、正常追踪、左移和抬升在真机上观察到；约 5 cm 左移的方向与规定校准姿势一致。
- USB 数值采样约 5 分钟，17,994 个位姿均为正常状态，最大到包间隔 34 ms，无超过 250 ms 的断流。该数据验证了这一段采样链路；完整可见连续性仍需同框证据。
- 现有手动位移没有实物刻度；精度、完整旋转/恢复项目、同框视频与投屏回归仍待完成。Wi-Fi 曾出现超过 250 ms 的长间隔，不能套用 USB 的结果。

当前可交付并体验的是 **S1 空间追踪模式**。正式验收完成前保留“实体验收待完成”，不提前将 S2 置为已开始。
